# SmartKNN Examples

This directory contains **small, runnable examples** demonstrating how to use
SmartKNN for common machine learning tasks.

All examples use **synthetic or lightweight data** and are intended for
learning and quick validation.

---

## Available Examples

- `regression_example.py` - Basic regression usage
- `classification_example.py` - Basic classification usage
- `ann_backend_example.py` - Fast inference using ANN backend
- `save_load_example.py` - Saving and loading SmartKNN models
- `auto_evaluation_example.py` - Automatic evaluation (classification / regression)

---

## Running an Example

From the project root:

```bash
python examples/regression_basic.py
```
